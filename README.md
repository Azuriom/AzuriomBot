# Azuriom Bot

[![Node.js CI](https://img.shields.io/github/actions/workflow/status/Azuriom/AzuriomBot/tests.yml?branch=master&style=flat-square)](https://github.com/Azuriom/AzuriomBot/actions/workflows/tests.yml)
[![Chat](https://img.shields.io/discord/625774284823986183?color=5865f2&label=Discord&logo=discord&logoColor=fff&style=flat-square)](https://azuriom.com/discord)

Support bot for the [Azuriom Discord server](https://azuriom.com/discord).

This bot is made in [TypeScript](https://www.typescriptlang.org/) with [Discord.js](https://discord.js.org/).

## Environment variables

* `DISCORD_TOKEN`: The Discord bot token
* `CATEGORY_FRENCH`: The ID of the category where messages should be sent in French
